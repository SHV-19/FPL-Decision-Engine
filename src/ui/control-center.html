Current-team authentication
One valid Official FPL authentication connection is required for actionable team decisions. Paste the OIDC record once (raw localStorage JSON, Chrome DevTools expanded object text, or only the raw refresh_token). After a successful connection, every actionable Deep Dive force-refreshes Official FPL /my-team first and validates all 15 players, XI, bench, captain, vice, bank, transfers and chip state. Screenshots never replace this authority. Credentials stay only in 06_CONFIG\_LOCAL_SECRETS; refresh tokens are rotated locally when FPL renews them.
