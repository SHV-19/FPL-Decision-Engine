# Decision Engine

**Prediction is not decision value.** A strong player forecast does not establish that a transfer is beneficial once the cost of a hit, future transfers, squad constraints, uncertainty and rank strategy are considered.

The decision system starts with canonical Official FPL player/team IDs and the authenticated current 15. Focused questions use scoped context; full-GW planning uses a deeper reasoning path. The model returns a structured proposal. Deterministic code checks ownership, transfer pairing, price/budget when available, 3-per-club limit, position totals, 15 unique players, legal XI/formation, a four-person bench with backup GK, and captain/vice starter legality.

HOLD preserves the squad. Source state from locked picks, cached squads or screenshots can inform discussion but cannot authorize a current-team Exact Call. Fixture opponents are grounded to Official FPL fixtures rather than generated prose.

The manager executes any changes separately through Official FPL; recommendations are not automatically applied.
