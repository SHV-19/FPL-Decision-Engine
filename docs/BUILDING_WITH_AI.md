# Building With AI

The project was built through AI-assisted development, with the human owner leading problem definition, product workflows, analytics and methodology decisions, data-source authority rules, validations, debugging, iterations and release execution.

AI in development should not be conflated with AI inside the product. The application has a Deep Dive reasoning component; deterministic checks, rather than free-form model prose, authorize executable FPL team recommendations.

This is not a claim that every line was manually engineered, nor that using AI removes ownership of requirements, architecture and QA.
