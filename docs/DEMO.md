# Demo walkthrough

This document describes the real workflow at the V4.1.2 checkpoint. A live public demo with seeded synthetic data is **not** currently claimed.

1. **Refresh.** Update public Official FPL data, then separately confirm the authenticated editable-team connection is healthy.
2. **Inspect team.** Resolve the actual 15-player squad with position, budget, transfer and fixture context.
3. **Ask a question.** A focused start/bench query takes a leaner reasoning path; a complete GW planning request gets deeper analysis.
4. **Review Exact Call.** Proposed transfers, XI, bench, captain/vice and chips are shown only when a structured proposal passes legality checks.
5. **Act.** The human manager makes any actual transfer or lineup change in Official FPL.
6. **Matchday.** Follow locked Official picks with Official event-live points and separate projected-rank enrichment.
7. **Close and learn.** Archive the GW, compare prediction/recommendation/action/outcome evidence, and distinguish decision process from luck.

Screenshots containing real account, rival or private-research data are intentionally not included.
